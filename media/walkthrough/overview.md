# The overview

**Show Settings Overview** lists every setting with:

- where it comes from: **Shared**, **Local**, **Overridden** (yours wins) or **Removed**
  (your `null` hides the team's value);
- the team's value, yours and the effective one;
- **Move to local**, **Move to shared** and **Remove override**.

Settings changed in `settings.json` that haven't been sorted yet are listed at the top,
with **Just me**, **Team** and **Discard**.

The status bar shows the mode and turns yellow when something needs you: a file that
doesn't parse, unsorted settings, or a pull that needs the file unhidden.
